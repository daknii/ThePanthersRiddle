Optional custom music
=====================

Drop an audio file named `theme.mp3` in this folder to layer your own track
on top of the generated ambience. It loops, fades in after "Entrar", gets
muffled on darker pages (failure, /subsolo...), and the generated ambience is
lowered underneath it.

No file? No problem: the generated soundtrack plays on its own.

To use a different file name or format, change CUSTOM_TRACK_URL in
src/audio/audioEngine.ts.
